# Concept imagery

The two raster photographs were generated with the built-in image-generation tool using the approved mockup 09 as a style reference. The original PNGs were retained; the theme uses WebP copies at the same 1536 × 1024 dimensions for smaller transfer size.

Theme paths:

- assets/hp-hero-concept.webp
- assets/hp-story-concept.webp

Both are illustrative concepts. They do not document a real product, supplier, customer, parcel or fulfillment process.

## Hero prompt

Use case: product-mockup. Asset type: standalone photographic hero asset for HiParcelo's Shopify homepage. The reference image is a style reference ONLY; generate a new photograph, not a webpage. A photorealistic horizontal editorial photograph of a matte sage-green modular desk organizer in an open UNBRANDED kraft parcel box on an oak desk. A modern smartphone leaning beside it shows a simple photograph of the organizer, no readable text. Cream tissue, indoor plant softly blurred. Warm side daylight, refined tactile materials, calm sophisticated cream/sage palette with a small navy detail. Main objects arranged on right two-thirds; left one-third has generous light cream negative space. Horizontal 3:2 composition. No logos or branding on box, no prices, no stars, no webpage headers or buttons, no overlays, no watermark. Match the photographic mood of reference 09. This is illustrative concept imagery for a preview, not a photo of an actual offered product.

## Story prompt

Use case: product-mockup. Asset type: standalone supporting lifestyle photograph for HiParcelo's Shopify homepage. The reference is a style reference ONLY. A refined photorealistic editorial photograph of a person's hand placing a pen in a matte sage-green desk organizer on a tidy oak desk. A notebook, scissors, leafy plant and laptop edge. Focus on useful everyday organization, visible proportions and beautiful tactile materials. Warm natural side daylight, calm cream/sage/navy palette. Horizontal 3:2 composition, no logos, no readable text, no webpage elements, no watermark. New separate photograph, not a webpage. Illustrative concept imagery for a preview, not a photo of an actual offered product.
